# 🐦 fedora-plasma-canary

A Fedora bootc image with git master Plasma and KDE Gears, plus a full KDE development toolchain. Perfect for KDE developers who want to hack on Plasma itself.

## Features

- Plasma (git master)
- KDE Gears (git master)
- KDE development tools and dependencies
- Development utilities: `kdevelop`, `flatpak-builder`, `clang`, `neovim`, `zsh`
- Preinstalled `kde-builder` with shell completions
- Enabled system services: `podman.socket`, `NetworkManager`, `bluetooth`, `cups`, and more

## How it is built

The image is Fedora Kinoite rawhide with its KDE packages swapped for a nightly build of KDE git master.

1. **Build KDE Master** (`kde-build.yml`, nightly) mirrors the newest Kinoite rawhide it can find to `ghcr.io/silverhadch/fedora-plasma-canary-kinoite`, builds KDE with `kde-builder` inside it, and packages every project as its own RPM, `kde-canary-<project>`. A `kde-canary` metapackage obsoletes the Fedora packages the build replaces. The RPMs are published to the `kde-nightly-<branch>` release.
2. **Build container image** (`build.yml`) installs those RPMs on the same pinned Kinoite in a single `dnf5 install`, so dnf swaps Fedora's KDE out and resolves everything the build needs.

Runtime dependencies come from the RPMs themselves, generated by rpmbuild from the built files, and from Kinoite, which already carries the desktop platform. The only hand-maintained package list is `build_files/image-packages.txt`, the development layer.

## ⚠️ This is a canary image

This image tracks KDE git master and Fedora rawhide. It **will** break. It is intended for KDE developers and contributors who want to run and hack on the latest Plasma, not for daily driving by regular users.

## Rebase to This Image

```bash
sudo rpm-ostree rebase ostree-unverified-registry:ghcr.io/silverhadch/fedora-plasma-canary:latest
```

Reboot afterwards to apply the image.
